# sheltr_core

Framework-free Dart library for Sheltr: signed-bundle parsing, Ed25519 verification, SQLite content store, keyword and vector retrieval, sync, and settings.

Used by the Flutter app in `apps/flutter`. See the repository root [`README.md`](../../../../README.md).
