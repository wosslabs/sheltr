# Support

Sheltr is a free, non-profit, offline-first disaster preparedness guide. It is
**not** an official warning system. Follow alerts from your local authorities.

## Where to get help

| Topic | Where |
|-------|--------|
| Bugs and feature ideas | [GitHub Issues](https://github.com/wosslabs/sheltr/issues) |
| Security vulnerabilities | [SECURITY.md](SECURITY.md) — private reporting only |
| How to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Publishing a signed bundle | [docs/publishing.md](docs/publishing.md) |

There is no guaranteed response time. Maintainers review issues when they can.

## What we do not provide

- Emergency advice beyond what is already in the approved corpus
- Official agency support or confirmation of local alerts
- Hosted content updates until a signed bundle is published (see README Status)
