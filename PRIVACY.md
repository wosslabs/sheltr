# Privacy policy

Sheltr is a free, non-profit disaster preparedness guide. It is built so that it does not need to know anything about you.

## What the app collects

Nothing. Sheltr has no accounts, no analytics, no advertising and no tracking. It contains no third-party tracking code.

## What stays on your device

- The guidance content you downloaded or that shipped with the app.
- Your settings: country, language, text size, high contrast.
- Your searches. They are answered on the device and are not sent anywhere.

## Location

The app does not request or use your location. You choose a country in Settings if you want guidance for it ranked first.

## Network use

The app's only network request is to download updated guidance from the publisher's static file host, over HTTPS. That request is a plain file download; the app sends no identifier and no account. Like any web request, the host can see your IP address and the time of the request. The app checks the digital signature of the downloaded content before using it, and keeps the previous content if the check fails.

## Permissions

Internet access, to download updated guidance. Nothing else.

## Children

Sheltr collects no personal information from anyone, including children.

## Changes

If this policy changes, the new version is published in this repository (`PRIVACY.md`) and noted in the app's release notes.

## Contact

Open an issue in this repository, or report a security problem as described in `SECURITY.md`.

Sheltr is an independent project. It is not an official government or agency service, and it is not an official warning system. Follow alerts from your local authorities.
